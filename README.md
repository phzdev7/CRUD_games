# 🎮 CRUD Games

Projeto desenvolvido em **Java** para simular o gerenciamento de uma loja de jogos.

O objetivo principal é praticar conceitos fundamentais de programação e desenvolvimento de sistemas, evoluindo o projeto gradualmente conforme novos conhecimentos são adquiridos.

## 🛠️ Tecnologias

* Java
* ArrayList
* Programação Orientada a Objetos
* Git e GitHub

## 📌 Funcionalidades

* Cadastro de jogos
* Listagem de jogos
* Busca de jogos
* Atualização de informações
* Remoção de jogos
* Gerenciamento de estoque

## 📚 Objetivo do projeto

Utilizar este projeto como laboratório de aprendizado, colocando em prática conceitos de **Java, POO, CRUD e boas práticas de desenvolvimento**.
